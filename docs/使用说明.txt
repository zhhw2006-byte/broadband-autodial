一、这个工具是做什么的
----------------------------------------------------------------------

装上之后，电脑会自动帮你拨号上网，并在断线后自动重连。

具体会在以下时机自动拨号：
  · 开机启动
  · 用户登录
  · 屏幕解锁（从锁屏界面返回桌面）
  · 网络意外断开后 10 秒

同时带一个"防打扰"机制：如果你连续两次主动断开网络
（10 分钟之内），工具会认为你是故意要断网，自动停止重拨 30 分钟，
不会跟你抢控制权。

本工具由 弥琉 制作。使用中遇到问题，可通过 QQ 458423691 联系。


----------------------------------------------------------------------
二、安装前需要准备什么
----------------------------------------------------------------------

1. 一台 Windows 10 或 Windows 11 的电脑
2. 宽带账号和密码（运营商给你的那个，不是 WiFi 密码）
3. 管理员权限（安装时会弹出 UAC 提示，点"是"即可）

如果你的电脑里还没有宽带连接，不用担心，安装过程中会自动帮你创建。


----------------------------------------------------------------------
三、安装步骤
----------------------------------------------------------------------

第 1 步
  把 宽带自动拨号-一键部署.bat 放到电脑上任意位置（桌面即可）。
  注意：只需要这一个文件，不需要其他文件。

第 2 步
  双击运行。如果弹出"你要允许此应用对你的设备进行更改吗"，
  点【是】。

第 3 步
  出现菜单后，输入数字 1，按回车。

第 4 步
  工具会检查你电脑上已有的宽带连接：
    · 如果只有一条，直接选中它
    · 如果有多条，会让你选择用哪一条
    · 如果一条都没有，会自动帮你新建一条

第 5 步
  按提示输入宽带账号和密码。密码输入时不会显示字符，这是正常的。

第 6 步
  等待几秒，看到"安装完成"和"自检通过"就成功了。

第 7 步（可选但建议）
  工具会问"现在拨号测试一次？"，输入 y 回车。
  如果显示"拨号成功，账号密码有效"，说明账号密码正确。

小提示：在任何输入步骤中，输入 b 并回车即可返回主菜单，
        不会对电脑做任何修改。

安装完成后，这个窗口可以关闭。


----------------------------------------------------------------------
四、安装后电脑上多了什么
----------------------------------------------------------------------

1. 一个计划任务，名称是「自动拨号宽带」
2. 一个文件夹 C:\ProgramData\AutoDialGuard\，里面放着运行脚本和日志
3. 可能新建了一条宽带连接（如果原来没有的话）

这些内容在卸载时会被完整清除。


----------------------------------------------------------------------
五、日常使用
----------------------------------------------------------------------

【断线了怎么办】
  不用管，10 秒内会自动重连。

【我想主动断网，但总是被自动连上】
  连续断开两次即可。第二次断开后，工具会停止重拨 30 分钟。
  30 分钟后恢复正常。

【想查看它到底有没有在工作】
  打开这个文件，用记事本查看：
    C:\ProgramData\AutoDialGuard\guard.log
  每次触发都会记录一行，能看到"已连接跳过""拨号成功""冷却中"等状态。

【想临时彻底关掉自动拨号】
  按 Win + R，输入 taskschd.msc 回车，
  在列表里找到「自动拨号宽带」，右键 → 禁用。
  想恢复就右键 → 启用。


----------------------------------------------------------------------
六、修改宽带账号密码
----------------------------------------------------------------------

双击运行工具 → 输入 2 → 按提示操作。

当前的值会作为默认值显示，直接回车表示沿用原来的。
输入完新密码后，工具会同步更新连接里保存的凭据。

修改在下次触发时生效，不影响当前已经连上的网络。


----------------------------------------------------------------------
七、卸载
----------------------------------------------------------------------

双击运行工具 → 输入 3 → 输入 y 确认。

卸载会清除以下内容：
  · 计划任务「自动拨号宽带」
  · 安装目录 C:\ProgramData\AutoDialGuard\（含日志、状态、标记文件）
  · 所有由本工具创建的宽带连接（可能有多条，卸载前会逐条列出）
  · 工具产生的电话簿备份文件

不会动的东西：
  · 你自己创建的其他宽带连接
  · 系统网络设置

卸载结束后会做一次残留检查，如果显示"未发现残留"就是清干净了。


----------------------------------------------------------------------
八、删除指定的宽带连接
----------------------------------------------------------------------

双击运行工具 → 输入 4。

这个功能用于删除某条具体的宽带连接，比如不再使用的旧连接。

操作流程：
  1. 工具列出所有宽带连接
  2. 输入要删除的序号，多个用逗号分隔（例如 1,3）
  3. 工具列出将要删除的清单
  4. 输入大写 YES 确认（必须是大写）

安全机制：
  · 正在使用中的连接不允许删除，会提示你先手动断开
  · 如果删的是最后一条连接，会明确警告删除后无法上网
  · 删除前自动备份电话簿

关于"空白条目"：
  如果电话簿里存在损坏的空白条目，会显示为「(无名称)」并标注
  「空白条目，选中后将被清除」。选中它，工具会先连续三次复核确认
  确实无效，才会清除。


----------------------------------------------------------------------
九、仅新增账号 / 查看状态
----------------------------------------------------------------------

【仅新增宽带账号】
  双击运行工具 → 输入 5。

  这个功能只往系统里添加一条宽带连接并保存账号密码，
  不会安装任何自动拨号配置，也不会有任何后台行为。

  适合场景：
    · 想给这台电脑加一个备用宽带账号
    · 暂时不需要自动拨号，只想手动连接

  注意：
    · 用这种方式【新建】的连接，会被登记为本工具创建，
      卸载时会一并删除。
    · 如果选择的是电脑上已有的连接（不是新建），
      则不会被登记，卸载时也不会删除。

【查看当前状态】
  双击运行工具 → 输入 6。

  会显示以下信息：
    · 计划任务状态、触发器数量、上次运行结果
    · 当前使用的连接名、账号、是否在线
    · 最近 8 行运行日志

  遇到问题需要反馈时，把这一页截图发给作者即可。

十、常见问题
----------------------------------------------------------------------

【双击后窗口一闪就没了】
  可能是杀毒软件拦截。Windows Defender 或 360 等对
  "批处理调用 PowerShell"的行为比较敏感。
  解决办法：把该文件加入杀毒软件的白名单/信任列表，再运行。

【提示"需要管理员权限"但没有弹窗】
  右键点击文件 → 选择"以管理员身份运行"。

【拨号失败，错误码 628 / 691】
  账号或密码不正确。也可能是宽带欠费停机。
  请核对运营商给的账号密码，然后用菜单 [2] 重新输入。

【拨号失败，错误码 651】
  网卡或 PPPoE 端口问题。多见于工具自动新建的连接。
  可以到「设置 → 网络和 Internet → 拨号」里查看该连接是否正常。

【拨号失败，错误码 678】
  线路无响应。检查网线是否插好、光猫是否通电、
  光猫是否已设置为桥接模式。

【拨号失败，错误码 769】
  指定的目标不可达。通常是网卡没有连接网线。

【提示"这是系统中最后一条宽带连接"】
  说明删除后电脑将无法拨号上网。如果只是想清理旧连接，
  建议先新建一条可用的连接，再删除旧的。

【提示"该连接当前正在使用中，无法删除"】
  工具不会替你断开正在用的连接（避免你远程操作时突然失联）。
  请先手动断开：点任务栏网络图标 → 选中该连接 → 断开，
  然后再执行删除。

【安装后没有自动拨号】
  1. 打开 C:\ProgramData\AutoDialGuard\guard.log 看有没有记录
  2. 如果没有记录，检查计划任务是否被禁用（taskschd.msc）
  3. 如果有记录但拨号失败，看错误码对照上面的说明


----------------------------------------------------------------------
十一、注意事项
----------------------------------------------------------------------

1. 工具会保存你的宽带账号密码，用于自动拨号。
   这些信息只存在你自己的电脑上，不会上传到任何地方。

2. 宽带密码修改后，需要重新运行工具用菜单 [2] 更新，
   否则自动拨号会一直失败。

3. 如果修改了 Windows 登录密码，本工具不受影响
   （它不依赖 Windows 密码运行）。

4. 建议不要在远程操作时删除正在使用的连接。

十三、卸载不干净怎么办
----------------------------------------------------------------------

如果卸载时提示某些内容无法删除（通常是被占用），
可以按以下步骤手动清理：

1. 删除计划任务
   Win + R → taskschd.msc → 找到「自动拨号宽带」→ 右键删除

2. 删除安装目录
   直接删除文件夹 C:\ProgramData\AutoDialGuard\

3. 重启电脑后再运行一次卸载，通常就能清干净

----------------------------------------------------------------------
十四、后记：这个脚本在制作时遇到的困难与解决方案
----------------------------------------------------------------------

这个工具最初的形态，只是一个"断线自动重连"的计划任务。
真正做成能交付给别人的成品，中间踩了不少坑，记录在这里，
一是给遇到类似问题的人参考，二是提醒自己别再犯同样的错。


【一】计划任务在跑，但拨号一直失败

最初现象是任务执行了，日志里也有记录，但网络始终不通，
报错 628。查下来是两处问题叠加：
  · 连接名写错了，系统里根本没有这个名字
  · 账号密码和连接对不上

教训：任何"按名字找东西"的逻辑，都必须先确认那个名字在
目标机器上真实存在，不能凭假设。


【二】想在事件触发器里按连接名过滤，做不到

原计划是让触发器只在"指定的那条宽带断开"时才响应。
但实测发现，Windows 网络事件日志的查询语法不支持在
EventData 层做条件过滤，中文名、英文名都失败。

解决办法：触发器只按事件 ID 匹配，把"是哪条连接"的判断
下沉到脚本里做。功能上等价，而且更可靠。


【三】需要在没登录的时候就能上网

远程办公场景要求电脑停在登录界面时网络已经通了。
计划任务的运行身份有三种，差别很大：
  · 只在用户登录时运行  —— 不满足要求
  · 存密码运行          —— 可靠，但改密码后会失效
  · S4U（不存密码）     —— 同样支持未登录，且不受改密码影响

最终选了 S4U。代价是该身份访问不了网络共享，
但拨号不受影响，因为拨号凭据是直接传给拨号组件的。


【四】打包成单个文件后，双击一闪就没

为了让用户只收一个文件，把脚本以编码形式内嵌进了 bat。
结果双击后窗口瞬间消失，没有任何提示。

原因是竞态：bat 把脚本释放到临时目录后启动它，脚本发现不是
管理员，于是提权并立即返回；而 bat 在脚本返回后马上删除了
临时文件——等提权后的新进程去读时，文件已经不在了。

教训：父进程启动子进程后立即清理资源，必须考虑子进程的启动
延迟。提权场景下这个延迟能有好几秒。


【五】连接名显示成一个字

列表里明明只有一条连接，却只显示第一个字。

原因是 PowerShell 的一个特性：函数返回单元素数组时，会被自动
"展开"成字符串。调用方取第 0 项，拿到的就是第一个字符。

这个问题只有在"系统里恰好只有一条连接"时才会出现——
而这恰恰是绝大多数用户的实际情况。


【六】删除连接时卡死

用户输入确认后界面毫无反应。

原因是清理尾部空行的循环用了范围表达式。当数组只剩一个元素时，
该表达式会取到两个元素，导致数量在 1 和 2 之间反复震荡，
形成死循环。

这又是"单条数据"场景才会触发的边界问题。


【七】三条连接只显示成一行

修完"显示一个字"的问题后，我换了一种写法强制返回数组，
结果与调用方的包裹叠加，产生了嵌套数组——三条连接变成一个
元素，元素里面才是数组。

最终采用最朴素的写法：函数正常返回，调用方统一包裹。
简单，而且三种规模都对。


【八】电话簿被清空

删除唯一一条连接后，电话簿变成空文件，电脑彻底失去拨号能力，
而工具当时没有任何提示。

现在加了两道防护：
  · 删除最后一条连接时明确警告
  · 电话簿里的空白/残缺条目自动清理，并在列表中标注


【九】安装目录可能被普通用户利用

ProgramData 默认允许普通用户在子目录中创建文件。如果守护脚本
被删除，有人可以放一个同名脚本进去，而计划任务是以最高权限
运行的——这等于一条提权通道。

现在安装时会收紧目录权限，普通用户只能读取和执行，
不能再往里面写东西。


【十】记录只能存一条连接

最初用一个文件记录"本工具创建了哪条连接"，但只存了一个名字。
结果通过"仅新增账号"功能添加的连接无法被卸载清理。

现在改为每行一个名字的列表，支持任意多条，并兼容旧格式。

所以如果你在使用中遇到问题，欢迎反馈——
