# 宽带自动拨号（Windows）

> 给 Windows 加一个"永不掉线"的宽带连接。断线 10 秒自动重连，开机即连，无需登录。

[![Platform](https://img.shields.io/badge/platform-Windows%2010%20%7C%2011-0078D6?logo=windows)](https://www.microsoft.com/windows)
[![PowerShell](https://img.shields.io/badge/PowerShell-3.0%2B-5391FE?logo=powershell)](https://learn.microsoft.com/powershell/)
[![License](https://img.shields.io/badge/license-MIT-green)](LICENSE)

---

## 这是什么

很多家庭宽带、出租屋宽带、小型办公网络需要 **PPPoE 拨号**上网。Windows 自带的拨号有两个麻烦：

- 断线后不会自动重连，需要手动点
- 开机后必须登录桌面才会拨号，远程场景用不了

这个工具把这两件事一次解决：装完之后电脑自己管好网络，你基本可以忘了拨号这回事。

**只有一个文件，双击就能装。**

---

## 特性

| 特性 | 说明 |
|---|---|
| **断线自动重连** | 网络断开后 10 秒内自动重拨 |
| **开机即连** | 开机、登录、解锁三种时机都会触发 |
| **未登录也能上网** | 使用 S4U 身份运行，停在登录界面时网络已通 |
| **不打扰** | 连续两次主动断网后，自动停止重拨 30 分钟 |
| **失败退避** | 拨号失败时重试 3 次，每次间隔递增 |
| **单文件部署** | 一个 `.bat`，无需安装依赖，无需联网下载 |
| **可完整卸载** | 卸载时清除任务、脚本、日志、标记文件，以及工具创建的连接 |
| **只删自己的** | 通过标记文件区分，用户原有的宽带连接一律不动 |

## 快速开始

### 方式一：直接使用（推荐给普通用户）

1. 到 [Releases](https://github.com/zhhw2006-byte/broadband-autodial/releases/latest) 下载 `broadband-autodial-v1.0.0.bat`
2. 双击运行，UAC 弹窗点「是」
3. 输入数字 `1`，按提示输入宽带账号密码
4. 完成

详细操作步骤见 [使用说明](docs/使用说明.txt)。

### 方式二：从源码构建

```powershell
git clone https://github.com/<your-name>/broadband-autodial.git
cd broadband-autodial
powershell -ExecutionPolicy Bypass -File build\Build-SingleFile.ps1
```

构建脚本会自动检查源码编码、语法，并在打包后做往返一致性校验。

## 工作原理

```
┌─────────────────────────────────────────────┐
│  计划任务「自动拨号宽带」                     │
│  触发器：开机 / 登录 / 解锁 / 网络断开        │
│  身份：当前用户 + S4U + 最高权限              │
└──────────────────┬──────────────────────────┘
                   │ 触发
                   ▼
┌─────────────────────────────────────────────┐
│  C:\ProgramData\AutoDialGuard\              │
│    autodial-guard.ps1   守护脚本（含凭据）    │
│    state.json           断线计数与冷却状态    │
│    guard.log            运行日志（512KB 轮转）│
│    created-entry.txt    本工具创建的连接名    │
└──────────────────┬──────────────────────────┘
                   │ 判断
                   ▼
        已连接？──是──▶ 记录并退出
             │
             否
             ▼
        冷却中？──是──▶ 退出
             │
             否
             ▼
        rasdial 拨号 ──▶ 成功 / 失败（退避重试）
```

**关键设计**

- **为什么用 S4U 而不是"存密码运行"**：S4U 不需要保存 Windows 登录密码，用户改密码后任务不会失效，同时支持未登录运行。
- **为什么触发器不按连接名过滤**：Windows 网络事件日志的 XPath 不支持在 `EventData` 层做条件过滤，只能按事件 ID 匹配，把连接名判断放在脚本里做。
- **为什么凭据明文写在脚本里**：`rasdial` 需要明文密码。脚本放在 `ProgramData`，目录权限已收紧为「普通用户只读」，且 Windows 的 `rasdial` 本身也不支持加密传递。这是该方案的固有限制，请知悉。

## 系统要求

| 项目 | 要求 |
|---|---|
| 操作系统 | Windows 10 / 11（Windows 8 及以上亦可） |
| PowerShell | 3.0 及以上，推荐 5.1（系统自带） |
| 权限 | **管理员**（安装、修改、卸载均需要） |
| 网络 | PPPoE 拨号宽带（非 DHCP 直连、非固定 IP） |

> 普通账户可以安装，但需要在 UAC 弹窗中输入管理员凭据。此时计划任务会注册在该管理员账户名下。

## 已知限制

1. **杀毒软件可能误报** —— 批处理内嵌编码脚本再调用 PowerShell，是杀软常见的启发式特征。如被拦截，请加入信任列表。
2. **端口索引因机器而异** —— 自动创建连接时使用的 `PPPoE<n>-<n>` 端口号通过探测现有条目推断，全新机器上可能不准，表现为拨号报错 651。
3. **凭据以明文保存在本地** —— 见上文「工作原理」中的说明。
4. **不适用于 DHCP / 静态 IP** —— 本工具只处理 PPPoE 拨号场景。
